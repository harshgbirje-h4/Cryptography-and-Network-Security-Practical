# Experiment 12: Security Analysis of AES Block Cipher Modes (ECB vs CBC)

## Aim
To implement AES encryption and decryption using ECB and CBC modes and analyze the differences in ciphertext block patterns.

## Algorithm
AES-128

## Modes Used
- ECB (Electronic Codebook)
- CBC (Cipher Block Chaining)

## Features
- AES encryption using ECB mode
- AES encryption using CBC mode
- Decryption verification
- Ciphertext block analysis
- Comparison of total and unique ciphertext blocks
- Random Initialization Vector (IV) generation for CBC
